# ClipForge: актуальная версия

Исходники соответствуют установленному выпуску `account-views-20261027-v45`.

- Поиск подходящих видео среди первых 20 результатов.
- Автоматический монтаж 1080×1920, фрагменты 10–15 секунд, скорость, эффекты и звук.
- Управление своими аккаунтами и публикация через TikTok Studio / YouTube Studio.
- Вкладка просмотров TikTok с почасовой проверкой на сервере.
- Миграции базы до `0011_account_views` включительно.

Развёртывание и история изменений описаны в README.md. Параметры задаются через
`.env.example`, настоящие секреты создаются отдельно через `deploy.init_secrets`.

В репозитории нет рабочей базы, cookie, паролей, видео, резервных копий и ключей
сервера. Это исходный код программы; данные рабочего сервера переносятся отдельно
закрытым инструментом `deploy.data_transfer`.

`release-manifest.json` проверяет исходные файлы установленного выпуска.
Этот документ добавлен при подготовке репозитория GitHub.
